# 《绍宋》长社之战试点 · 情节核对

《绍宋》是榴弹怕水的架空历史小说，试玩场景依据卷二情节整理。赵玖是小说对宋高宗的再创作。小说情节与人物关系以相关章节为依据；界面秒数、城池及兵俑图标和资料栏中的部队状态用于章节演示。作品与章次可查[公开目录](https://www.hongxiu.com/bookquery/zfpewznjzfjd)。

## 关陕与陕州

在《绍宋》的西线叙事中，李彦仙守陕州，金军在关陕用兵。地图上的关陕说明用这一地点交代长社故事以外的局势。[卷一第10章](https://hetushu.com/book/8942/6431269.html) · [卷二第54章](https://hetushu.com/book/8942/6431399.html)

李彦仙任陕州知州、守城抗金并牵制金军西进，见《宋史》卷四四八。全国视图采用 1128 年疆域作时代参照，读者可分别从资料卡进入正史和小说章节。[《宋史》卷四四八《李彦仙传》](https://zh.wikisource.org/wiki/宋史/卷448#李彥仙)

## 本地精校全文补核

按用户提供的本地《绍宋》精校文本核对卷二第 62–71 章。以下记录了早期局部沙盘核对情节的依据。现版沿用这些章节和文字解说，在全国地图上定位城市；早期沙盘中的行军折线、箭头和队列动画仅作制作记录。

| 章节 | 原著中的因果 | 沙盘覆盖情况 |
| :-- | :-- | :-- |
| 62–63《召见》《问答》 | 杜岩揭发杜充与挞懒私约不战，也说明自己取道西平、中阳山回南阳的路线。赵玖先秘密召见诸臣，随后经城东暗门抵东寨。杨沂中、王德、张景等承担南向诱敌，刘晏护赵玖东渡白河。 | 先画杜岩回程，再切到赵玖反向夜行与南面佯动。暗门与渡河点采用情节概述。 |
| 64–65《堂论》《夜色》 | 林景默使掌城防的郦琼奉旨，张宪守县衙，岳飞出城召集诸将。赵玖先让岳飞负责临阵调度，随后处置杜充。入夜，胡寅认为这样处置有失妥当，赵玖意识到即使胜了，朝中的裂痕仍在。 | 已纠正授命与斧决顺序。胡寅夜议尚未演出。 |
| 66–67《决策》《进军》 | 李逵诈降提前递出消息，马皋等沿洧水北上。挞懒调蒲察鹘拔鲁去长葛设伏，岳飞原向临颍方向行军，随后转向长社。沿途举烟后，王彦作先锋，赵玖随大军自鄢陵出发。 | 马皋北上、金骑离开长社、岳飞折向清潩水分阶段演出。李逵递信由剧情提示交代。赵玖大队出发和接战仍分为两个操作阶段。 |
| 68《来回》 | 岳飞半渡，在西岸背桥列阵。金骑击溃徐庆所部，徐庆阵亡，但岳飞本阵仍在。王彦趁金骑尚未收拢自上游抢渡。守城的韩世忠判断还有后援，仍按兵不出。 | 金骑推进至徐庆阵、徐庆部散开、岳飞本阵留在河边，随后八字军从上游渡河。韩世忠在城头观察由剧情交代。 |
| 68–69《来回》《并旗》 | 龙纛过河进入岳飞本阵，韩世忠见旗立即出兵。解元、王善从东、南门出，韩世忠与成闵率背嵬军从城墙豁口突围。赵玖入阵后令郦琼传令拆桥，隔断金军回援。会师后，韩世忠请龙纛向挞懒将台移动，韩、岳并旗，诸军跟进。 | 亮旗、拆桥和突围已有可见状态。过桥有独立动画，渡毕后拆桥。突围仍以单支部队演示，会师后龙纛、韩字旗、岳字旗沿各自的短线共同向挞懒将台推进。 |
| 70–71《河滩》《或言南北》 | 洪涯带挞懒沿浊潩水方向脱离。鹘拔鲁北上在河滩接应挞懒过河，随后死于李逵与牛皋之手。长社解围后，诸将讨论北追、东进、西守，赵玖决定岳飞留镇五河，韩世忠与王彦北追，自己经鄢陵往东京。 | 浮桥阻断、金军沿河北上、河滩接应和战后军令依次呈现。河滩位置为剧情示意。 |
